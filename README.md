# Plantbox · 仓储作业平台

基于 React、TypeScript、React Three Fiber 和 Three.js 的交互式仓储园区。

## 本地运行

需要 Node.js 22.18+（推荐 Node.js 24）。

```sh
npm install
npm run dev
```

打开 http://localhost:5173 。开发服务器使用固定端口 5173。

```sh
npm test         # 库存、车辆运动学、碰撞及 30 分钟真实物理搬运检查
npm run build   # TypeScript 检查与生产构建
npm run preview # 预览 dist 生产构建
```

## 已实现

- 一个完整的滨河仓储园区：双坡仓库、室内货架、三个月台、玻璃办公区、堆场、道闸、道路、围栏与绿化。
- 原生三维程序化模型；静态几何按材质合并，字体随项目本地分发，运行不依赖模型或字体 CDN。
- 三辆卡车的入园、靠台、装卸、离场与运输循环，三台后轮转向叉车的插叉、举升、低位运输和落货。
- 带唯一编号的独立托盘刚体：场内货物预先存在；橙色车卸货后留在收货位；另两辆车装车后将托盘保留在各自货位，随车离场。
- 卡车以前/后轴约束驱动：停稳换挡、连续转向弧线倒库、直线慢靠台、出库让行、回转驶离；前轮采用阿克曼转向，六个车轮按各自路程滚动。
- 场景对象选择、详情侧栏、视角切换、缩放、旋转、屋顶展开、标签开关、园区导览和全屏。
- 库存表、预留与可用库存、库存预警、模拟补货、运输运单和作业流水。
- 全局搜索、暂停/继续、1×/5×/10× 倍速与模拟重置。
- 桌面精细光影（环境遮蔽、阴影、色调映射）和移动端默认流畅模式，可在设置中切换。
- 响应式布局、移动端详情面板、键盘焦点管理与弹窗快捷键。

## 操作

- 左键拖动旋转、右键拖动平移、滚轮缩放；触屏支持单指旋转与双指缩放。
- 点击模型、场景标签、月台或设备列表，查看相应详情。
- `Space` 暂停/继续；`⌘K` / `Ctrl+K` 打开搜索；`Esc` 关闭弹窗。

## 启动性能

基础园区、物理引擎与精细光影分别加载。第一帧就包含车辆、叉车和全部初始托盘；Rapier 使用同一份纯数据快照接管这些对象，准备完成前模拟时钟保持不动，用户的暂停选择也会保留。精细光影随后启用，最终高画质参数与原版一致。

同类托盘及叉车车身共享不可变几何体，各托盘仍保有独立对象、编号和物理刚体。字体使用从原始 TTF 无损转换的 WOFF2，保留原字形、字重及许可证。Three.js 和 Rapier 使用独立的内容哈希文件名；验证过单独修改界面文字不会改变这两个库的文件名。

2026-10-05 与提交 `a1d5b03` 的生产构建对比：Apple M4 Pro、Chrome 无头浏览器、1440 × 900、关闭浏览器缓存，每种条件各测 3 次取中位数。两版均通过 Vite 生产预览启用 gzip，限速为下载 6 Mbps、延迟 80 ms。

| 指标 | 优化前 | 优化后 | 变化 |
| --- | ---: | ---: | --- |
| 限速下含全部初始托盘的首轮 3D 绘制 | 2.930 s | 1.186 s | 缩短 59.5% |
| 本机直连、同一首屏指标 | 0.481 s | 0.506 s | 增加 25 ms，主要收益在网络等待 |
| 基础 3D 脚本传输量 | 1,134 KB | 259 KB | 减少约 77% |
| 完整启动资源传输量，含后续物理与光影 | 1.712 MB | 1.399 MB | 减少 18.3% |
| 首屏字体传输量 | 479 KB | 167 KB | 减少 65.1% |

限速下，优化版精细光影约 1.65 秒就绪，物理作业约 2.49 秒就绪；园区可先查看和操作镜头。首屏指标由相同浏览器探针记录：42 个托盘标签已创建后的第一次 WebGL 绘制调用，不等同于浏览器 LCP，也不代表所有设备或真实线上网络。拆分主要改善可见时机与缓存复用，传输总量下降主要来自字体压缩。原始逐次时序摘要见 [`benchmarks/loading.json`](benchmarks/loading.json)。

复测工具为 `scripts/measure-loading.cjs`，需运行环境提供 Playwright 和 Chromium；可以用 `PLAYWRIGHT_MODULE` 指定已安装的 Playwright 模块路径、`CHROME_PATH` 指定 Chrome 可执行文件。先执行 `npm run build` 和 `npm run preview`，再运行：

```sh
node scripts/measure-loading.cjs http://localhost:4173/ /tmp/plantbox-loading.json
```

字体可用安装了 `fonttools` 和 `brotli` 的 Python 运行 `scripts/convert-fonts.py` 重新生成。源 TTF 留存用于复现，页面只请求 WOFF2。

部署时使用 `dist`，为带哈希的 `/assets/*` 配置 `Cache-Control: public, max-age=31536000, immutable`，为 HTML 使用重新验证策略，并启用 gzip 或 Brotli。实际线上缓存和压缩需要在对应托管平台配置；本次仅验证本地生产预览，未更改远程部署。
- “查看仓内”切换屋顶；视角菜单可直接聚焦月台、堆场、仓内或俯视。

## 模拟边界

这是规划中的单站点首版，尚未扩展到五个站点。演示数据不是实时业务数据，未接入 WMS、ERP、传感器或后台服务。

所有视图共享模拟时钟和物理交付流水。货物实际落位后才结算库存；仅到达计划时间不产生交付。单轮演示最多运行 30 分钟场内时间，结束后可重置。刷新页面会恢复初始状态。

货柜的“装载估算”仅按标准托盘货物体积计算容积占用，不包含三维排箱、重量分配或运输约束求解。

## 卡车轨迹

当前模型是约 9.5 米长的整体式厢式货车。运动参考点设在后双轴中点，等效轴距 6.485 米；后轴最小转弯半径设为 9.5 米，内侧前轮最大转角约 38.4°。这些参数来自场景模型尺寸及演示设计，不代表某款实车的标定数据。

入库流程：沿入口车道前进越过泊位，停稳，倒车转入泊位，回正后直线减速靠台。驶离时先留出清障距离，再沿连续曲率弯道进入出口车道。角度直接由后轴路径的切线确定，满足 `yawRate = speed × curvature`，不再把平移与车头旋转分别补间。

一轮现在为 840 秒，每托盘预留 120 秒，装卸区间为第 50–770 秒，离场至第 825 秒，留出插叉、举升、低速搬运和交叉让行时间。三辆演示车使用固定放行时隙；不是任意车辆数量的实时调度器。转弯区已按整车外廓扩展，测试每 0.025 秒检查整轮车辆及关键静态设施的重叠。后双轴简化为等效单后轴，不计算轮胎形变、悬架动力学或半挂铰接角。

参考：

- [MathWorks：Bicycle Kinematics](https://www.mathworks.com/help/robotics/ref/bicyclekinematics.html)——以后轴中心定义位姿、由轴距和转角约束转弯半径。
- [California DMV：Truck Drivers](https://www.dmv.ca.gov/portal/driver-education-and-safety/special-interest-driver-guides/truck-drivers/)——倒车前选好起始位置、低速倒车并及时修正；其中挂车操作规则不直接套用到当前整体式货车。

## 叉车与物品

三台叉车分别服务相应月台。装车托盘从预置的 6 个货位、每位 3 层库存中逐件取走，取最上层、直线退离后降至运输高度；不会在下一轮凭空补回。橙色货车的货物从到场时就存在于车内，卸货后逐层落在 6 个收货位上。每个托盘是 800 × 1200 mm 的包装货物组合体，拥有稳定的 `PAL-月台-批次-货位` 编号。点击托盘或叉车可查看关联关系。

叉车按前轴滚动约束与后轮转向规划路径，包含清障退车、低速回转、停稳换向、低位运输、停车升降、慢速送入、落货和空叉退出。后轮角度、车尾外摆、门架后倾、货叉升降和车轮滚动随动作变化。车辆和货叉是运动学刚体，托盘是 Rapier 动态刚体，采用重力、带叉孔的复合碰撞体与 1/120 秒固定步长。接触货叉且举升离开支承面后，建立临时刚体约束近似稳定载荷；落货前释放约束，再由重力和目标支承面完成放置。它不是无限摩擦、轮胎或柔性包装材料的高精度仿真。

出库托盘完全落到车厢接收区后，确认交付并保留原物体；每车 6 个独立货位避免叠放，货物在实际落位姿态上固定，随货车转弯和离场，驶出场景后才回收。下一轮到场的出库车辆为空车，旧货物不会重新出现。入库托盘留在地面/已卸货托盘上。库存、装卸进度与流水读取同一份物理交付记录，装车确认时扣减一次，离场不重复扣减；切到库存页后物理搬运仍继续。启动、重置和跳时使用一致的场景快照重建；叉车搬运中的托盘由接触与临时约束驱动，车内固定货物随车厢运动，不将托盘挂到叉车节点上。如果目标货物缺失或未落位，不会靠计时结算。

参考：[OSHA 货物装卸步骤](https://www.osha.gov/etools/powered-industrial-trucks/operating-forklift/load-handling)、[OSHA 行驶与后轮转向](https://www.osha.gov/etools/powered-industrial-trucks/operating-forklift/traveling-maneuvering)、[Rapier 刚体与接触](https://rapier.rs/docs/user_guides/javascript/rigid_bodies/)。
